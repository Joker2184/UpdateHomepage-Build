## 优化
- 将默认优先选取的 Java 版本从 Java 25 改为 Java 21，以增加 Mod 兼容性
- 若由于 Java 版本有误而崩溃，会明确提示在版本设置中修改 Java 版本
- 证书验证失败也会被视作网络异常，以给出更有效的错误提示

## Bug 修复
- 特定情况下崩溃：“ToolTip”不能有逻辑或视觉父级（#8876，@lactobionicAcid）
- 使用新闻主页或杂志主页预设时崩溃（#8877，@muhuixue）
- 无法删除部分文件夹（#8878，@Peacock-Que）
- 版本设置中指定的 Java 无法保存（#8879，@Parckerz）
- 鼠标从特定被禁用的控件上移开不会使 Tooltip 消失（#8882，@MovTery）
- 当打开中的 Tooltip 改变时，其显示不会动态地改变（#8891，@iPodtouch6557）
