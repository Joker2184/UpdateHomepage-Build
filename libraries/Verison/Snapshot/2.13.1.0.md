- 快速双击开始下载按钮会导致出错（#8222，@lyt20）
- 若在调试设置中设置了过慢的动画速度，动画可能完全卡死（#8260，@OtoNoOwariNi）
- 资源详情页的版本名称可能有多余的 .zip 后缀（#8467，@ZerkyLiu）
- 特定系统环境下，从老版本 PCL 迁移 Java 列表会失败（#8911，@jkugjhikg）
- 弹出提示在特定情况下不会正常消失（#8917，@Peacock-Que）

- 下载整合包时，内置的地图不会被放到对应文件夹内（#8965，@LinLei0102）
- 资源列表加载出错时的错误信息有误（#8898，@wxk66）
- 在 Mojang 更新资源索引后，MC 可能一次性地缺失资源文件（#8908，@Howard302）
- ValidateFolderPath 中的 NTFS 8.3 文件名检查存在冗余（#8994，PR @qinghuayuci）

- 不应将证书异常识别为连接超时

- 当文件/文件夹没有短路径名的时候，会无法压缩短路径
- 部分 Modrinth 整合包无法下载，提示文件大小有误
